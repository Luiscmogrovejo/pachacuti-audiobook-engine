# Prologue (sample text)

> **Sample text.** This file is NOT book content. It is a fixture written for
> this public repository and dedicated to the public domain (CC0) so that the
> application, the encryption pipeline and the Playwright suite can run without
> the real manuscript. The real chapter text is private and is not distributed
> here.

Stone is in no hurry. It waits for water, it waits for wind, it waits for the
hand that will move it, and if no hand comes it waits all the same, because
waiting is the one thing a stone does well. A river passes. Another river
passes. The mountain changes shape so slowly that no eye can catch it, and yet
it changes.

That is the whole of the story this sample tells: a stone, a river, and enough
time for each to notice the other.
